# Trabalho em Grupo — Algoritmos de Ciência de Dados

**Disciplina:** Ciência de Dados

**Objetivo:** Pesquisar, compreender e apresentar um algoritmo utilizado em Ciência de Dados, explorando seus fundamentos, funcionamento, aplicações, vantagens e limitações.

### Temas dos trabalhos

| Grupo | Algoritmo | Principal aplicação |
|---|---|---|
| 1 | **XGBoost** | Previsões e classificações com dados tabulares |
| 2 | **CatBoost** | Aprendizado com dados categóricos |
| 3 | **Isolation Forest** | Detecção de anomalias e fraudes |
| 4 | **HDBSCAN** | Agrupamento de dados e descoberta de padrões |
| 5 | **UMAP** | Redução de dimensionalidade e visualização |
| 6 | **Autoencoders** | Aprendizado de representações e detecção de anomalias |
| 7 | **TabPFN** | Modelos fundacionais para dados tabulares |
| 8 | **Chronos-2** | Previsão de séries temporais com modelos pré-treinados |

### Estrutura obrigatória da apresentação

**1. Introdução ao algoritmo**
- O que é e para que serve?
- Qual problema busca resolver?
- Quando foi desenvolvido e por quem?
- A qual categoria pertence (aprendizado supervisionado, não supervisionado, Deep Learning etc.)?

**2. Funcionamento do algoritmo**
- Como funciona, passo a passo?
- Quais são seus principais conceitos e fundamentos?
- Como os dados são processados?
- Apresentar exemplos, diagramas ou ilustrações que facilitem a compreensão.

**3. Exemplo didático de funcionamento (obrigatório)**

Cada grupo deverá apresentar **um exemplo didático que demonstre como o algoritmo funciona, mesmo sem utilização de programação**.

O exemplo deverá ilustrar, de maneira clara e progressiva, como o algoritmo recebe os dados, realiza seu processamento e produz os resultados.

Para isso, poderão ser utilizados:
- Fluxogramas explicativos.
- Sequências de imagens ou diagramas.
- Pequenos conjuntos de dados fictícios.
- Tabelas demonstrativas.
- Simulações conceituais ou animações.
- Exemplos passo a passo de execução do algoritmo.

**Importante:** o objetivo é demonstrar que o grupo compreendeu efetivamente a lógica de funcionamento do algoritmo, sendo capaz de explicá-la de forma didática aos demais colegas.

**4. Aplicações práticas**
- Em quais situações o algoritmo pode ser utilizado?
- Apresentar exemplos reais de aplicação em Ciência de Dados.
- Quais tipos de dados ou problemas são mais adequados?

**5. Vantagens e desvantagens**
- Quais são seus pontos fortes?
- Quais são suas limitações?
- Quais são seus requisitos e desafios de utilização?

**6. Comparação com outros algoritmos**
- Identificar pelo menos um algoritmo alternativo que resolva problemas semelhantes.
- Explicar suas principais diferenças.
- Apontar em quais situações cada abordagem seria mais indicada.

**7. Demonstração prática com programação (opcional)**
- Implementar o algoritmo, preferencialmente em Python.
- Utilizar um dataset público ou um exemplo reproduzível.
- Apresentar e interpretar os resultados.
- Se possível, comparar seu desempenho com outro algoritmo.

**8. Conclusão**
- Sintetizar os principais conhecimentos adquiridos.
- Explicar quando seria recomendável utilizar o algoritmo.
- Apresentar as referências bibliográficas e fontes consultadas.

### Critérios de avaliação

| Critério | Pontuação |
|---|---:|
| Compreensão e domínio do algoritmo | 2,0 |
| Explicação do funcionamento | 2,0 |
| Exemplo didático obrigatório | 2,0 |
| Aplicações práticas e exemplos reais | 1,0 |
| Análise de vantagens, limitações e comparação | 1,5 |
| Organização, clareza e qualidade da apresentação | 1,5 |
| **Total** | **10,0** |

**Atividade complementar (bônus):** até 1,0 ponto adicional pela implementação, demonstração e interpretação de resultados, respeitando a nota máxima de 10,0.

### Orientações gerais

- O trabalho será realizado em grupos.
- Todos os integrantes deverão participar da apresentação.
- O tempo sugerido é de **15 a 20 minutos por grupo**, com mais 5 minutos para perguntas.
- O exemplo didático de funcionamento é obrigatório, independentemente da realização de uma implementação computacional.
- A implementação em Python ou outra linguagem é opcional e poderá contribuir para a pontuação adicional.
- É permitido utilizar imagens, fluxogramas, animações e demonstrações para explicar o funcionamento do algoritmo.
- Os alunos deverão demonstrar compreensão do algoritmo, evitando apresentações baseadas apenas na leitura de slides.
- As fontes utilizadas deverão ser identificadas.
